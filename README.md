# ☀️ Daylight (데이라이트) - 하루 계획 & 24시간 맞춤 집중 타이머 with 치즈냥이 🐱

> **"당신의 하루를 비추는 따뜻한 플래너 & 사랑스러운 치즈냥이 파트너"**  
> 파스텔 라벤더 & 크림 감성의 할 일 관리(To-Do), 최대 24시간 맞춤 집중 타이머, 마우스로 들어올릴 수 있고 똥도 치워줄 수 있는 귀여운 치즈냥이가 함께하는 웹 애플리케이션입니다.

---

## 📖 1. 프로젝트 소개
- **프로젝트 명**: Daylight (데이라이트)
- **개발 환경**: 순수 HTML5, CSS3, JavaScript (Vanilla JS)
- **데이터 보관**: 브라우저 내장 저장소 (`localStorage`)
- **특징**: 무거운 외부 라이브러리나 이미지 다운로드 없이 **순수 웹 표준 기술(SVG 벡터 그래픽 & Web Audio API & CSS 인터랙티브 애니메이션)**로 제작되어 어디서든 가볍고 즉시 실행되며, Vercel을 통해 클릭 몇 번으로 무료 배포할 수 있습니다.

---

## 📁 2. 파일 구성 및 역할

| 파일명 | 역할 설명 |
| :--- | :--- |
| **`index.html`** | 웹사이트의 뼈대(구조)를 담당합니다. 상단 로고, 오늘 날짜 표시, 달성률 진행 바, **24시간 맞춤 시간 설정기 및 대형 시계(HH:MM:SS)**, 할 일 목록, **치즈냥이 캐릭터**, 그리고 **똥 레이어(`poop-layer`)**를 포함합니다. |
| **`style.css`** | 사이트의 시각적 디자인을 담당합니다. 부드러운 크림과 라벤더 컬러 팔레트, **고양이의 배변 끙차 모션(`state-pooping`)**, **귀여운 만화 똥 및 모락모락 김 효과**, 청소 반짝이 폭죽 이펙트, 목덜미 들림 및 착지 바운스가 적용되어 있습니다. |
| **`script.js`** | 웹사이트의 동작과 인공지능 로직을 제어합니다. 할 일 관리, **사용자 맞춤 24시간 타이머 연산**, **고양이 배변 시퀀스 및 똥 클릭 청소**, **1분(60초) 자동 소멸 타이머**, 마우스 드래그 앤 드롭 이동을 처리합니다. |

---

## 🐱 3. 사랑스러운 치즈냥이 (Cheese Cat) 인터랙션

1. **💩 배변 모션 & 똥 치우기 인터랙션**:
   - 가끔씩 고양이가 걸음을 멈추고 엉덩이를 쑥 낮추며 *"끙... 끙차! 💩"* 하고 힘을 줍니다.
   - 1.8초 후 바닥에 귀여운 소용돌이 모양의 만화 똥(모락모락 김 포함)을 뿅! 남기고 *"시원하다냥! 🐾"* 말풍선을 띄웁니다.
   - **클릭해서 즉시 치우기**: 똥을 마우스로 클릭하면 퐁! 터지며 반짝이(`✨`, `🫧`) 파티클과 함께 즉시 깨끗하게 치워지고, 고양이가 *"집사야 깨끗하게 치워줘서 고맙다냥! ✨"* 감동의 말풍선을 남깁니다.
   - **1분(60초) 후 자연 소멸**: 클릭하지 않고 그냥 두더라도 정확히 1분이 지나면 스스로 은은하게 사라집니다. (50초 경과 시 깜빡이며 소멸 예고)
2. **마우스로 들어올리기 (Drag & Drop)**:
   - 고양이를 마우스로 꾹 누르면 뒷목을 잡힌 것처럼 **몸통과 앞발·뒷발이 아래로 길쭉하게 축 늘어지며 대롱대롱 매달리는 모션(`state-picked`)**을 취합니다.
   - 화면 안 원하는 위치 어디든 데려다 놓을 수 있습니다.
3. **말랑한 젤리 착지 (Landing)**:
   - 마우스를 놓으면 바닥에 통통 튀며 안착하는 부드러운 쿠션 바운스 모션 후 다시 편안하게 자리를 잡습니다.
4. **가볍게 톡 클릭 (Petting)**:
   - 가볍게 콕 누르면 핑크빛 하트(`💖`)와 함께 *"골골골..."*, *"집사야 오늘도 응원한다냥!"* 같은 사랑스러운 골골송을 불러줍니다.
5. **자율 산책 & 꾹꾹이**:
   - 화면을 아장아장 걷고, 자리를 잡고 앞발로 꾹꾹이를 하거나 식빵을 구우며 잠을 잡니다.

## ⏱️ 4. 최대 24시간 맞춤 집중 타이머

1. **내 마음대로 시간 설정**: 시간(0~24)과 분(0~59)을 직접 입력하거나, 퀵 버튼(25분, 1시간, 2시간, 4시간)으로 손쉽게 목표 시간을 지정할 수 있습니다.
2. **24시간 대형 디지털 시계**: 시:분:초(`HH:MM:SS`) 형식으로 남은 시간을 한눈에 보여줍니다.
3. **자유 스톱워치 모드**: 상단 탭을 눌러 목표 카운트다운 대신 0초부터 내가 공부한 시간을 쭉 측정할 수도 있습니다.
4. **오늘 총 집중 시간 영구 보관**: 브라우저를 새로고침하거나 껐다 켜도 오늘 공부한 총시간이 누적 보관됩니다.

## 🚀 5. 로컬 실행 및 배포 방법

- **로컬 실행**: `daylight` 폴더 안의 **`index.html`** 파일을 더블 클릭하면 브라우저에서 바로 실행됩니다.
- **Vercel 무료 배포**: GitHub에 파일을 올린 후 [Vercel](https://vercel.com)에서 Import하여 빌드 설정 없이 **Deploy** 버튼만 누르면 30초 안에 전 세계에 공개됩니다.
